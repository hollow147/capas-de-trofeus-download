# Capas de Troféus

Programa para Windows que sincroniza os seus troféus da PlayStation (PSN) e cria capas e vídeos no estilo stories para cada jogo: platinas, listas completas, metas, planos de platina e muito mais.

## Baixar

**[⬇ Baixar o instalador do Capas de Troféus (Windows 10/11)](https://github.com/hollow147/capas-de-trofeus-download/raw/atualizacoes/Instalar-Capas-de-Trofeus.exe)**

## Instalar

1. Abra o instalador baixado. Na primeira vez, o Windows pode mostrar "O Windows protegeu o computador": clique em **Mais informações › Executar assim mesmo** (o programa não tem assinatura paga da Microsoft).
2. Clique em **Instalar**. Ele instala só para o seu usuário (sem senha de administrador), cria o atalho na área de trabalho e no menu Iniciar e aparece em *Configurações › Aplicativos* (dá para desinstalar por lá).
3. O programa abre na janela própria dele, sem abas nem barra de endereço.
4. No programa, entre com a sua conta da PSN seguindo os passos da tela. As suas chaves e senhas ficam só no seu PC, protegidas pelo Windows.

## Manual

O **MANUAL.html** (aqui ao lado) explica cada opção do programa: onde fica e o que faz, com busca. Ele é feito pelo próprio programa e sai atualizado a cada versão. Dentro do programa: aperte **F1** › **Manual completo**.

## Atualizações

O programa procura versão nova sozinho a cada 3 horas, confere se o arquivo é o original e se atualiza quando você não estiver usando.

## Privacidade

Nada da sua conta sai do seu PC, a não ser para os serviços que você mesmo ligar (PSN, Telegram, Discord, Google Drive…). Este repositório só tem o programa pronto (`capas-de-trofeus.exe`) e o arquivo da versão (`versao.json`).
